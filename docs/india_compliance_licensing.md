# India Compliance Licensing & Cost Guide

## Overview
This document provides complete information about India Compliance app licensing, costs, and business model for Vecmocon's ERPNext implementation.

## Cost Structure

### Free Components (No Cost)
✅ **App Download & Installation** - MIT licensed, no fees  
✅ **GST Calculations** - CGST, SGST, IGST calculations  
✅ **Tax Templates** - Pre-configured Indian tax templates  
✅ **Chart of Accounts** - Indian accounting standards  
✅ **Compliance Workflows** - Basic GST compliance features  
✅ **Localisation Features** - Indian address formats, etc.  
✅ **Development & Testing** - Full functionality for development  

### Paid Components (Credits System)
💳 **API Calls to Government Portals** - e-Invoicing, e-Way bills, GST verification  
💳 **Real-time GST Validation** - Live GST number verification  
💳 **Automated Compliance Reports** - Direct GSTR filing integration  
💳 **Government Portal Integration** - NIC, GST portal connectivity  

## Credit System Details

### Free Trial
- **Credits:** 500 API requests
- **Validity:** 3 months from email verification
- **Activation:** Automatic after email verification
- **Usage:** Full API functionality for testing

### Paid Credits
- **Pricing:** Pay-per-use model (₹X per 1000 requests)
- **Minimum Purchase:** 1000 credits per annum
- **Additional:** Multiples of 1000 credits
- **Validity:** 1 year (extends with new purchases)
- **Billing:** Invoice sent to registered email
- **Refund Policy:** Non-refundable

### Credit Usage
- **1 Credit = 1 API Request**
- **Balance Check:** Available in system (updates every 10 minutes)
- **Usage Tracking:** Integration request logs
- **Account Management:** My Account page in ERPNext

## Business Model

### Revenue Streams
India Compliance generates revenue through:
- **Credit Sales** - API usage fees
- **Support Services** - Priority technical support
- **Consulting** - Implementation assistance
- **Training** - Workshops and documentation
- **Custom Development** - Tailored modifications

### Why This Model?
- **Government API Costs** - NIC/GST portal fees are passed through
- **Compliance Critical** - Ensures reliable service for tax compliance
- **Scalable** - Pay only for actual usage
- **Accessible** - Free for development and small businesses
